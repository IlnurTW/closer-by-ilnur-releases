# Closer by Ilnur — releases

This public repository is reserved for accepted, signed production releases of Closer by Ilnur. It does not contain the product source code, customer configurations, API keys, SSH keys, or passwords.

No production release has been published yet. Unsigned QA builds are not for customer deployment.

When production acceptance is complete, each release will include signed Windows binaries, Linux server binaries, a signed release manifest, checksums, SBOM, and a publisher-signed update feed. Release immutability is enabled; all assets must be attached to a draft before publication.
